What is a time series?

A time series is just data collected over time, like the sunlight measured every week. It usually mixes three things: a slow trend, a repeating season, and random noise. Our goal is to predict the future part of the line.

Watch the lines draw: blue = slow trend, purple = yearly season, grey = random noise, white = what we actually measure (all three added together). Forecasting means separating the predictable parts (trend and season) from the noise.

What is stationarity?

A series is stationary when it hovers around a steady average instead of drifting off. Most forecasting methods are built for steady series, so we test for it and fix it if needed.

Not stationary: drifts upward
Stationary: wobbles around a flat average
The test (ADF): its p-valueThe chance of seeing results like these if the series really were drifting. Below 0.05 (5%) we conclude the series is steady. Above, we can't rule out drifting. tells us if the series is steady. Our sunlight series passes. The strong yearly cycle is still removed on purpose by a "seasonal difference" (compare each week with the same week last year).

Our improved model (SARIMAX) — and what about LSTM?

SARIMAX is SARIMA plus extra inputs (the "X"). Here the extras are last week's humidity, temperature and cloud cover. Everything else is identical, so any improvement comes only from the weather.

What is an LSTM? not used in this project

An LSTM is a neural network that keeps a "memory" of long past patterns and can learn curved, complicated relationships that SARIMA-type models cannot. It needs more data tuning and is harder to explain. We did not build one; comparing SARIMAX with an LSTM is listed under future work.

Dataset and method notes
  • Data: NASA POWER daily point data (all-sky surface shortwave radiation, humidity, temperature, cloud amount), one grid point per city. A satellite and reanalysis product, not a ground sensor.
  • Weekly means (Mon–Sun), window 2000-01-01 to 2026-07-30 (cloud amount is not yet published after that). 80/20 chronological split.
  • Forecasts are true one-week-ahead: SARIMAX uses only last week's weather. Parameters are fixed after training.
  • Significance: Diebold–Mariano test on squared errors.
  • The "forecast simulator" uses the SARIMA parameters learned on the training weeks, updated through the end of the modelling window (26 Jul 2026), and is checked against NASA POWER values published afterwards.
Plain-English glossary
kWh/m²/day
Sunlight energy landing on one square metre in a day. About 5.4 is typical here.
MAE
Average miss, in the same units as sunlight. Easiest to understand. Smaller is better.
RMSE
Like MAE, but big misses count extra.
MAPE
Average miss as a percentage of the real value.
Seasonal naive
Guess that next week equals the same week last year. A model must beat this to be useful.
Naive
Guess that next week equals this week.
p-value
How likely a difference this size is to be pure chance. Below 0.05 = "statistically significant".
Residual
Actual minus predicted: the miss.
